# S42 Agent v0.1.1 — Context compaction and live tool output

**English** · [Español](https://github.com/stock42/s42-agent/blob/v0.1.1/docs/releases/v0.1.1.es.md)

This prerelease includes all changes since v0.1.0, focused on continuing coding
work, seeing actual tool progress and keeping conversation history clear.

## Changes

- Removed harness quotas for tokens, steps, time, files, attachments and tool
  payloads. Commands and requests run until completion, explicit cancellation
  or a real error. Actual provider capacities and errors still apply.
- Automatically compacts the complete active context near 85% of the model's
  reported context window, preserving the original session history and previous
  tool effects. Reports context usage next to input/output tokens and tok/s;
  distinguishes reported usage, estimates and unknown capacity.
- Shell stdout/stderr now appears while the command is running. Completion or
  cancellation preserves its full output once in the session. Verification
  guidance tells the agent to close timers and other resources opened by checks.
- Notices, failed/cancelled turns and compaction reasoning stay in chronological
  order, including after reopening. Historical errors no longer appear after
  activity from a later turn.
- Selecting chat text automatically copies it through the terminal clipboard
  protocol (OSC 52), with Unicode and real line breaks. Mouse release, Ctrl+A
  and Shift+arrows are supported; copying requires terminal support/permission.
- Content search accepts a file path as well as a directory, avoids ENOTDIR and
  explicitly reports no literal matches. Its pattern is literal text, not regex.
- DeepSeek reasoning-only partials are sent back with empty text content instead
  of null; HTTP failures display the provider's detail. Output capacities come
  from provider metadata instead of fixed harness token budgets.
- Updated Spanish/English tool catalogs and guides, community links and
  repository sponsorship information.

## Downloads and installation

Assets include six executables: Linux glibc, macOS and Windows, each x64/ARM64;
SHA-256 checksums; build manifest; Unix/PowerShell installers; MIT license; and
`s42-agent-0.1.1-all-platforms.tar.gz` containing the complete distribution.
Binaries include Bun. The LLM server/models and external commands remain separate.

See [installation](https://github.com/stock42/s42-agent/blob/v0.1.1/README.md#installation),
the [user guide](https://github.com/stock42/s42-agent/blob/v0.1.1/docs/USAGE.md) and
the [tool contracts](https://github.com/stock42/s42-agent/blob/v0.1.1/docs/TOOLS.md).
Existing configuration and sessions are retained. Restart the agent after updating.
Source development requires Bun 1.4.2; npm publication is not part of this release.

## Validation and scope

Source tests cover fragmented UTF-8, context compaction, tool recovery, project
isolation, clipboard payloads and chronological history. PTY checks exercise
live command output, resize, cancellation and terminal restoration. The release
workflow runs typecheck/tests, builds all targets and smoke-tests Linux x64
outside the checkout without Bun/Node in PATH before packaging the assets.

Real DeepSeek accepted a copied conversation with 83,530 input tokens and
completed a verification-script repair on an isolated copy. This is provider
and DOM-mock evidence, not visual browser gameplay or a full 1M-token window test.
Windows/macOS/ARM64 executables are cross-built; their native runtime and physical
terminal mouse/drop behavior remain unverified.

Tools use the user's permissions and have real effects. Details of the checks
and release process are in the
[release guide](https://github.com/stock42/s42-agent/blob/v0.1.1/docs/PUBLISHING.md).
