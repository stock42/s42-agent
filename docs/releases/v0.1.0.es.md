# S42 Agent v0.1.0 — QBasic se encuentra con la IA local

[English](https://github.com/stock42/s42-agent/blob/v0.1.0/docs/releases/v0.1.0.md) · **Español**

La primera **preview** de S42 Agent: un harness de coding desarrollado con
TypeScript/Bun y un espacio de trabajo de terminal inspirado en QBasic.

## Características principales

- Ventanas clásicas de terminal, menús, mouse y navegación inspirada en Vim.
- Pestañas de proyectos simultáneos con sesiones, modelos y borradores independientes.
- WebServer por proyecto con puerto configurable y preview en navegador.
- Explorador entre carpetas, búsqueda por nombre/glob y colores HTML/CSS/JS/TS.
- Presets llama.cpp y DeepSeek, además de proveedores compatibles configurables.
- Respuestas en streaming, visibilidad del razonamiento recibido, actividad de
  tools, tokens de entrada/salida y promedio tok/s.
- Doce tools nativas de Bun para archivos, búsqueda, HTTP, comandos, Markdown,
  WebSocket, skills internas y scraping de páginas renderizadas.
- Servidores de tools MCP stdio/HTTP con CRUD y activación/desactivación.
- Skills internas/externas, instrucciones bajo demanda y buscador skills.sh.
- Biblioteca de promptings con `{{variables}}`.
- UI español/inglés y seis paletas: QBasic, Graphite, Forest, Nord, Dracula, Gruvbox.
- Configuración/historial SQLite nativo y API keys en el llavero del SO.
- El mismo agente desde CLI sin TUI, con instrucciones del proyecto y tools.

## Empezar

Esta preview incluye instaladores por usuario y seis ejecutables: x64 y ARM64
para Windows, Linux y macOS, más checksums SHA-256.
Consultá la [instalación en español](https://github.com/stock42/s42-agent/blob/v0.1.0/README.es.md#instalación)
o [en inglés](https://github.com/stock42/s42-agent/blob/v0.1.0/README.md#installation)
para instalar con un comando. Los binarios incluyen Bun; ejecutar desde fuente
requiere Bun 1.4.2. Las URLs de descarga se activan al publicar esta release.
El repositorio sigue privado: descargar assets requiere acceso GitHub autorizado.
Descargá y extraé el all-platforms.tar.gz; después ejecutá su instalador local.

```bash
git clone https://github.com/stock42/s42-agent.git
cd s42-agent
bun install --frozen-lockfile
bun run dev
```

Requiere Bun 1.4.2 y un terminal ANSI de al menos 60×16. Configurá el modelo en
Models y Nombre + Carpeta del proyecto en Projects. El servidor LLM y el modelo
son independientes; tool calling requiere un modelo y template compatibles.

Para ejecutar sin TUI:

```bash
bun run index.ts --llm_server http://127.0.0.1 --llm_port 8080 \
  --prompting "Desarrolla un Tetris con sonido en un único archivo HTML" --reasoning off
```

Este ejemplo escribe en la carpeta actual. Usá `--cwd` para elegir otro proyecto.
Consultá el [README](https://github.com/stock42/s42-agent/blob/v0.1.0/README.es.md)
y el [manual](https://github.com/stock42/s42-agent/blob/v0.1.0/docs/USAGE.es.md).

## Validación y alcance

La validación local incluyó tests de fuente, interacción PTY, CLI Linux instalado,
TUI compilada y coding con un modelo real. Consultá la
[guía de contribución](https://github.com/stock42/s42-agent/blob/v0.1.0/CONTRIBUTING.es.md)
para checks de fuente y la [guía de release](https://github.com/stock42/s42-agent/blob/v0.1.0/docs/PUBLISHING.es.md)
para comandos de build y smoke.

Linux x64 tiene evidencia de runtime local. Los cross-builds Windows/macOS/arm64
no demuestran ejecución en destino; siguen pendientes el runtime por SO y
mouse/drop físicos en terminal. Los seis binarios x64/ARM64 para Linux, macOS y
Windows se acompañan de checksums SHA-256 y un manifiesto de builds.

Las tools se ejecutan con permisos del usuario y efectos reales. Scraping necesita
un navegador instalado en Linux/Windows; los flujos PDF requieren un renderizador.
MCP soporta tools; resources/prompts, sampling, elicitation y OAuth no están
implementados.
