# S42 Agent v0.1.0 — QBasic meets local AI

The first **preview** of S42 Agent: a coding harness built with
TypeScript/Bun and a terminal workspace inspired by QBasic.

## Highlights

- Classic terminal windows, menus, mouse support and Vim-inspired navigation.
- Concurrent project tabs with independent sessions, models and drafts.
- A project WebServer with a configurable port and browser preview.
- File explorer across folders, filename/glob search and HTML/CSS/JS/TS colors.
- llama.cpp and DeepSeek presets plus configurable compatible providers.
- Streaming responses, provider-emitted reasoning visibility, tool activity,
  input/output token counts and average tok/s.
- Twelve Bun-native tools for files, search, HTTP, commands, Markdown, WebSocket,
  internal skills and rendered-page scraping.
- MCP stdio/HTTP tool servers with CRUD and enable/disable controls.
- Internal/external skills, on-demand instructions and a skills.sh finder.
- A prompting library with `{{variables}}`.
- Spanish/English UI and six themes: QBasic, Graphite, Forest, Nord, Dracula, Gruvbox.
- Native SQLite configuration/history and API keys in the OS keychain.
- The same agent from a headless CLI, including project instructions and tools.

## Get started

This preview includes user installers and six compiled executables: x64 and
ARM64 for Windows, Linux and macOS, plus SHA-256 checksums.
See [English installation](https://github.com/stock42/s42-agent/blob/v0.1.0/README.md#installation) or
[instalación en español](https://github.com/stock42/s42-agent/blob/v0.1.0/README.es.md#instalación)
for one-command setup. Binaries contain Bun; running the source requires
Bun 1.4.2. Download URLs become active when this release is published.

```bash
git clone https://github.com/stock42/s42-agent.git
cd s42-agent
bun install --frozen-lockfile
bun run dev
```

Requires Bun 1.4.2 and an ANSI terminal (at least 60×16). Configure your model
in Models and your project's Name + Folder in Projects.
The LLM server and model are separate; tool calling requires a compatible model
and template.

For headless use:

```bash
bun run index.ts --llm_server http://127.0.0.1 --llm_port 8080 \
  --prompting "Build a single-file HTML Tetris game with sound" --reasoning off
```

This example writes in the current folder. Use `--cwd` to select another project.
See [README](https://github.com/stock42/s42-agent/blob/v0.1.0/README.md) and the
[user guide](https://github.com/stock42/s42-agent/blob/v0.1.0/docs/USAGE.es.md).

## Validation and scope

The [distribution validation](https://github.com/stock42/s42-agent/blob/v0.1.0/docs/qa/distribution.md)
records the local checks: 177 passing tests, installed Linux CLI and compiled TUI.
Earlier [real GLM coding QA](https://github.com/stock42/s42-agent/blob/v0.1.0/docs/qa/reliable-coding-and-sqlite.md)
includes a generated, independently exercised Tetris artifact.

The recorded v0.1.0 Linux benchmark reports 24.43 ms startup p95 and 46.64 MiB
idle RSS. It measures PTY bytes with hot OS cache, excluding graphical painting
and LLM inference. It is a historical binary result, not a rerun of this source.
[Full method](https://github.com/stock42/s42-agent/blob/v0.1.0/docs/qa/final-validation.md).

Linux x64 has local runtime evidence. Cross-builds for Windows/macOS/arm64 do
not establish runtime support; destination execution and physical terminal
mouse/drop coverage remain pending. The six binaries (x64/ARM64 for Linux,
macOS and Windows) are accompanied by SHA-256 checksums and a build manifest.
[Distribution validation](https://github.com/stock42/s42-agent/blob/v0.1.0/docs/qa/distribution.md).

Tools run with the user's permissions and real effects. Scraping requires an
installed browser on Linux/Windows; PDF workflows require a renderer.
MCP tools are supported; resources/prompts, sampling, elicitation and OAuth are
not implemented.
