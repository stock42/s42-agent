04 / FAQ

Questions before you start?

Installation, models, credentials and what happens to your code.

What is S42 Agent?

An open-source coding agent with a QBasic-style terminal UI and a headless CLI. It works in your project folder, uses your chosen LLM and can read, edit and execute tools with your user permissions.

Is it free?

S42 Agent is distributed under the MIT license. The harness has no subscription. A remote LLM provider may charge for its API; local models use your own hardware.

Do I need to install Bun or Node?

The compiled executable includes Bun, so it runs without a separate Bun installation. Developing from source requires Bun 1.4.2. External shell commands, LLM servers and MCP programs are installed separately. Optional Chrome DevTools MCP requires its own Node and Chrome setup.

Which models can I use?

llama.cpp is the default provider. DeepSeek and other Chat Completions-compatible endpoints are supported. Configure the endpoint and key in Models, then select a real model ID. Tool calling and image support depend on the model and its server configuration.

Can I use it on a server over SSH?

Yes. Use the TUI in an ANSI terminal or run the same agent with --prompting without opening the TUI. LLM keys are stored in SQLite and do not require D-Bus or a desktop keychain. Browser features require their external browser setup.

Where are API keys saved?

In the credentials table of the agent’s local SQLite database, without additional encryption. With legacy JSON configuration, keys live in a neighboring config.json.credentials.sqlite file. Keys are separated by configuration, provider and endpoint. CLI key overrides stay in memory; environment variables are also supported. Previously saved OS-keychain keys must be entered once in Models.

Does my code stay on my computer?

Files and session history are stored locally. The selected LLM receives the context sent to it. With a remote provider, that context leaves your computer; a local model can keep inference local. Configured MCP servers and tools may also access external services.

How do plans, verification and Git work?

TODO.md and Kanban keep task progress. Verification records contain actual checks and evidence. The Git panel shows changes and history; commits and pushes follow AGENTS.md and the active project’s instructions. Generating AGENTS.md and initializing a Git repository are explicit actions.

Can I resume a long or cancelled task?

Yes. SQLite preserves sessions, partial responses and received reasoning. Reopen the session to continue. Context compaction uses the model’s reported window and retains the original history; cancellation does not undo files already changed or commands already executed.

Which platforms are available, and how do I update?

The release provides Linux glibc, macOS and Windows executables for x64 and ARM64. Linux x64 has native binary smoke validation; the other targets are cross-built. To update, close the agent and rerun the installer below. Configuration and sessions are retained.
