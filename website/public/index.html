03 / START BUILDING

One terminal.
One command.

The binary includes the Bun runtime. Install the agent, choose your model and open your first project.

Download the v0.1.1 preview ↗

x64 and ARM64 · Linux with glibc · macOS 13+ · Windows 10 1809+
The LLM server and models are configured separately.

Linux / macOSBash 
curl -fsSL https://raw.githubusercontent.com/stock42/s42-agent/main/install.sh | bash
WindowsPowerShell 
powershell -c "irm https://raw.githubusercontent.com/stock42/s42-agent/main/install.ps1|iex"
From sourceGit + Bun 1.4.2 
git clone https://github.com/stock42/s42-agent.git
cd s42-agent
bun install --frozen-lockfile
bun run dev

The installers verify SHA-256. Then open a new terminal and run s42-agent. Full guide ↗
