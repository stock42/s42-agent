03 / EMPEZÁ A CREAR

Una terminal.
Un comando.

El binario incluye el runtime de Bun. Instalá el agente, elegí tu modelo y abrí tu primer proyecto.

Descargar la preview v0.1.1 ↗

x64 y ARM64 · Linux con glibc · macOS 13+ · Windows 10 1809+
El servidor LLM y los modelos se configuran por separado.

Linux / macOSBash 
curl -fsSL https://raw.githubusercontent.com/stock42/s42-agent/main/install.sh | bash
WindowsPowerShell 
powershell -c "irm https://raw.githubusercontent.com/stock42/s42-agent/main/install.ps1|iex"
Desde el código fuenteGit + Bun 1.4.2 
git clone https://github.com/stock42/s42-agent.git
cd s42-agent
bun install --frozen-lockfile
bun run dev

Los instaladores verifican SHA-256. Después, abrí otra terminal y ejecutá s42-agent. Guía completa ↗

TU PRIMER PROYECTO

  1. 01

    Abrí tu carpeta. Projects → Agregar proyecto. Solo nombre y carpeta.

  2. 02

    Elegí el modelo. Configurá el proveedor y seleccioná tu modelo en Models.

  3. 03

    Escribí tu idea. Enter envía. Shift+Enter agrega una línea. Seguí el trabajo en vivo.
